# Cortex AI Backend

A backend project developed as part of the **Zyro Internship Program – Week 1**.

This project focuses on setting up the basic backend foundation using **Python, FastAPI, and PostgreSQL**.

## Technologies Used

- Python
- FastAPI
- Uvicorn
- PostgreSQL
- Psycopg
- python-dotenv
- Git
- GitHub
